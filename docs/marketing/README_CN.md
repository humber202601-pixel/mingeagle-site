# MING EAGLE 第二批获客执行包

1. 解压后双击 `OPEN_ME.html`，选择渠道与脚本，复制英文文案和对应链接。这个文件不需要安装软件，也不会自动发布或发送消息。
2. `14-day-publishing-kit.md` 包含完整的10条英文视频口播、镜头安排、4条Facebook文案、14天建议节奏和效果复盘表。
3. `channel-links-and-scripts.json` 保存可迁移的数据，后续可导入其他工具。
4. 三个公开内容页：
   - https://www.mingeagle.com/learn.html
   - https://www.mingeagle.com/silent-basketball-vs-regular.html
   - https://www.mingeagle.com/custom-basketball-for-teams.html

先拍真实产品画面和LOGO工作室录屏，再配字幕。视频里可演示视觉预览，不能把预览说成已印刷实物。样品成本、物流、交期和最终印刷尺寸随报价确认。

TikTok、Instagram、YouTube使用“主页链接”时，一个主页链接会由多条视频共用，所以只能直接识别渠道；Facebook每条带参数的可点击链接可以识别对应文案。不要把主页链接来源当成逐条视频归因。

目前已准备材料，没有登录社交账号、发布帖子、投广告或提交Google/Bing索引请求。网站中询盘的Landing page、Referrer、Campaign信息用于后续判断渠道效果。
