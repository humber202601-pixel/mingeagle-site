# V14.2 机构官网社交账号发现

## 新增入口

客户发现 → 扩展来源 → 从机构官网发现社交账号。

输入机构官网，沿用上方州、英文城市和客户类型。先执行已有官网机构、业务和地区核验，通过后从同次读取的首页及最多三个机构内页识别 Facebook、TikTok、Instagram 和 LinkedIn 公司主页。

## 数据边界

- 读取官网公开 HTML 中的账号链接及机构结构化资料 sameAs，无需付费或平台登录。
- 仅保存完整账号主页。帖子、视频、群组、个人 LinkedIn 页面、短链、脚本示例和私有地址不作为账号线索。
- 每次最多二十个不同账号。规范化网址去重，证据保留官网页面、原始链接和链接文字。
- 官网引用链接不等于社交平台认证或账号当前可访问。所有新增记录仅进入待核验线索，不新增有效候选、不导入 CRM、不发送消息。
- 重复账号保留原记录，包括待核验、已转换和已忽略状态；不覆盖原始人工描述。
- 官网读取失败、业务或地区不匹配时不保存线索。零结果明确说明仅未找到可识别主页；动态内容和短链可能需要人工核实补录。

## 验证

SQLite 与模拟官网集成测试覆盖机构 sameAs、原始链接/出处保留、网址去重、个人或内容链接排除、私有地址和错误地区拒绝、已忽略机构保护、学校官网支持、不重复抓取官网、不新增候选/CRM/消息，以及既有公开来源搜索回归。

执行 npm run build、npm run test:discovery 及 Cloudflare Pages Functions 打包。生产环境验收另行记录。
