# mingeagle-site

Deployment trigger for the Cloudflare follow-up scheduler on the `v2-cloudflare` branch.

Deployment refresh to apply current Cloudflare Pages environment variables.

Deployment refresh to apply the Gmail OAuth refresh token secret.

Deployment refresh after production Gmail OAuth token rotation.

Deployment refresh after enabling `ADMIN_ACCESS_KEY` and `AUTO_EMAIL_ENABLED=true` for the follow-up scheduler.
