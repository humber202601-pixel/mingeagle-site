# MING EAGLE Admin V1

Phase 1A foundation for content separation.

## Files
- `public/admin.html`
- `public/admin.css`
- `public/admin.js`
- `public/data/site-content.json`

## Current features
- Product master editing
- Homepage settings
- FAQ editing
- Brand/contact settings
- Browser-local draft save
- JSON import/export
- Portable master content backup

## Safety
This work lives on the `admin-v1` branch and does not change the production `main` website.

## Not yet included
- Authentication
- Server/database persistence
- Secure GitHub publishing
- Media upload
- Automatic regeneration of all existing product HTML

## Next phase
1. Validate `site-content.json` automatically.
2. Generate catalog/site output from the content master.
3. Add Preview / Publish workflow.
4. Add secure authentication and media storage.
